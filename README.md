## 이 저장소에 대해

### 문서의 역할

같은 프로젝트를 여러 곳에서 소개하므로, 어느 곳이 원본인지 정해 둡니다.
**사실은 이 README의 프로젝트 목록이, 서술은 프로젝트별 마크다운이 원본**이고 나머지는 이를 옮긴 것입니다.

| 위치 | 역할 | 원본 여부 | 담는 것 |
|---|---|---|---|
| 이 README의 프로젝트 목록 | 사실의 원본 | 원본 | 기간 · 인원 · 성격 · 링크(저장소, 시연 영상, 서비스) |
| `finch.md` · `pinlog.md` · `formabridge.md` · `harness.md` | 서술의 원본 | 원본 | 무엇을 결정했고, 무엇이 틀렸고, 무엇을 배웠는지 |
| [포트폴리오 사이트](https://trossyou.github.io/portfolio/) | 마크다운을 줄여 보여주는 화면 | 복사본 | 같은 사실, 줄인 본문. 내용은 `src/data/projects.ts`에 따로 적는다 |
| [GitHub 프로필 README](https://github.com/TrossYou) | 처음 들어오는 곳 | 복사본 | 목록의 사실, 한 줄 요약, 링크 |
| 포트폴리오 PPT (준비 중) | 제출 · 면접용 | 복사본 | 사이트 요약을 더 줄인 것 |
| 각 팀 저장소 README | 팀이 관리하는 서비스 소개 | 여기서 고치지 않음 | 서비스 소개와 실행 방법. 여기서는 링크만 건다 |

고치는 순서는 원본이 먼저입니다. 기간이나 인원 같은 사실이 바뀌면 이 목록을 먼저 고치고, 서술이 바뀌면 마크다운을 먼저 고친 뒤 복사본을 따라 고칩니다.
사이트 내용은 마크다운을 불러오지 않고 따로 적혀 있어 저절로 맞춰지지 않으므로, 마크다운을 고치면 `src/data/projects.ts`도 함께 확인합니다.

### 개발

```bash
npm install
npm run dev
```

빌드 결과는 `/portfolio/` 하위 경로를 기준으로 합니다. 루트 도메인에 올릴 때는 `BASE_PATH=/ npm run build`.

### 스택

React 19 · TypeScript · Vite · Tailwind CSS v4 · React Router · Motion · Lenis
