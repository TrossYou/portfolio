# 유승주 — 포트폴리오

프론트엔드 개발자 포트폴리오 사이트. 각 프로젝트에서 **무엇을 결정했고 무엇이 틀렸고 무엇을 남겼는지** 기록합니다.

배포: https://trossyou.github.io/portfolio/

사이트에는 요약본을, 마크다운 문서에는 전체 기록을 둡니다.

## 개발

```bash
npm install
npm run dev
```

빌드 결과는 `/portfolio/` 하위 경로를 기준으로 합니다. 루트 도메인에 올릴 때는 `BASE_PATH=/ npm run build`.

## 스택
