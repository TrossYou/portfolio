# TrossYou 디자인 시스템

프론트엔드 개발자 유승주(TrossYou)의 포트폴리오 사이트, GitHub README, 케이스 스터디 문서가 함께 쓰는 시스템입니다. 주제는 하나입니다. **무엇을 결정했고, 무엇이 틀렸고, 무엇을 남겼는지.** 잘 만든 결과물의 전시가 아니라 판단의 기록으로 읽히게 만듭니다. 화려함 대신 여백·둥근 모서리·선 하나로 정돈하고, 숫자는 전부 출처가 있습니다.

## 글의 규칙

- 한국어 평서문으로 씁니다. "~했습니다"가 기본이고, 케이스 스터디 제목만 "~했다"로 끊습니다. 영어 섹션 이름(About, Selected Work, How I Work)은 아이브로우 자리에서만 씁니다.
- 숫자에는 출처가 따라붙습니다. `StatTile`과 `SkillBar`에는 출처 줄이 필수이고, 출처를 적을 수 없는 숫자는 싣지 않습니다.
- 성향·인재상은 점수로 매기지 않습니다. "스스로 일을 찾아서 한다"는 레이더 차트의 축이 아니라 `TraitEvidence` 한 장입니다. 성향 라벨 하나에 근거 문장 하나와 링크 하나를 붙입니다.
- 이모지를 쓰지 않습니다. 느낌표도 쓰지 않습니다. 과장 수식어("최고의", "혁신적인")를 쓰지 않습니다.
- 한 문장에 한 가지만 담습니다. 본문 한 줄은 36~40자(약 680px)를 넘기지 않습니다.

## 색

- 바탕은 `ground`, 그 위에 뜨는 면은 `surface`입니다. 둘 다 차가운 기운이 살짝 도는 중립색이라 순백·순흑을 쓰지 않습니다.
- 남색은 두 가지로 나뉩니다. **채움**은 `accent`(이동 배지, 기본 버튼, 활성 점), **글자**는 `accent-text`(링크, 강조 라벨)입니다. 다크 테마에서 둘의 값이 다릅니다. 채움색 `accent`를 글자로 쓰면 다크에서 3.6:1로 떨어집니다. `accent` 위의 글자는 항상 `on-accent`입니다.
- 페리윙클은 채움 전용입니다. `tint`는 칩·콜아웃·제목 단어 뒤 하이라이트 띠, `tint-strong`은 섹션 제목 밑줄 막대, 스킬 막대, 타임라인 레일, 도표 채움입니다. 둘 다 글자색으로 쓰지 않습니다.
- 글자는 `ink`와 `muted` 둘뿐입니다. `muted`는 메타 줄·캡션·출처 줄·아이브로우에만 씁니다. 본문을 `muted`로 쓰지 않습니다.
- 상승·하락 같은 의미색은 이 시스템에 없습니다. 포트폴리오에는 상태를 알리는 숫자가 없기 때문입니다. 필요해지면 토큰을 추가하고 이 문단을 고칩니다.
- 모든 글자·바탕 쌍은 두 테마에서 4.5:1 이상입니다. 각 토큰의 설명에 쌍과 수치가 있습니다.

## 서체

- 본문과 제목은 `sans` 하나(IBM Plex Sans KR)입니다. 세리프를 섞지 않습니다. Pretendard를 쓰지 않은 이유는 포트폴리오 템플릿의 기본값이기 때문이고, 바꾸려면 `type.families.sans` 하나만 고치면 됩니다.
- 숫자·날짜·코드·아이브로우는 `mono`(JetBrains Mono)입니다. 메타 줄 "2026.08–09 · 6주 · 5인"처럼 숫자가 섞인 한 줄은 통째로 `meta` 스타일입니다. 숫자가 세로로 정렬되는 곳은 `font-variant-numeric: tabular-nums`를 켭니다.
- 아이브로우(`eyebrow`)는 대문자 영문에 자간 0.08em입니다. 한글은 대문자가 없으므로 아이브로우에 한글을 쓰지 않습니다.
- 한글 본문 행간은 1.7(`body` 16/27)입니다. 영문 기준 1.5로 내리지 않습니다.
- 제목에는 `text-wrap: balance`를 줍니다. 제목 안의 핵심 단어 하나에만 `ty-mark`(페리윙클 띠)를 깔 수 있습니다. 한 화면에 하나입니다.
- GitHub README에 들어가는 SVG는 웹폰트를 못 불러옵니다. 그 SVG는 `sans` 스택의 뒤쪽(Apple SD Gothic Neo, Malgun Gothic, system-ui)으로 렌더되는 것을 전제로 글자 폭에 여유를 둡니다.

## 면·선·모서리

- 구분은 그림자가 아니라 선으로 합니다. 기본 상태의 카드에 그림자가 없고, `shadow-soft`는 hover에만 붙습니다.
- 카드는 두 종류입니다. **스티커**(`ty-sticker`)는 `ink` 1.5px 테두리에 `radius-lg` 22px로, 프로젝트 카드와 히어로의 이미지처럼 한 화면에 한두 개만 둡니다. **일반 카드**(`ty-card`)는 `line` 1px에 `radius-md` 14px로, 통계·성향·콜아웃처럼 여러 개가 나란히 설 때 씁니다. 스티커를 격자로 깔지 않습니다.
- 왼쪽 세로 색띠로 강조하는 카드를 만들지 않습니다. 강조는 상단의 라벨 칩이나 아이브로우로 합니다.
- 모서리는 네 단계뿐입니다. 배지·코드·표는 `radius-sm`, 카드·이미지는 `radius-md`, 스티커·큰 이미지는 `radius-lg`, 버튼·칩은 `radius-pill`.

## 간격과 레이아웃

- 4px 배수의 아홉 단계(`space-1`~`space-9`)만 씁니다. 형제 요소 사이는 `gap`으로, 개별 margin을 쌓지 않습니다.
- 본문 최대 폭 680px, 그리드 최대 폭 1120px. 바깥 여백은 모바일 `space-4`, 데스크톱 `space-7`.
- 섹션 사이는 데스크톱 `space-9`, 모바일 `space-8`. 섹션 제목 위에 `space-8`.
- 히어로는 화면 높이에 맞추지 않고 내용 높이로 끝냅니다. 첫 화면 안에 Selected Work의 첫 카드가 걸리게 둡니다.
- 모바일 폭(400px)에서 모든 격자는 한 열로 접힙니다. 가로 스크롤은 표와 코드 블록에만 허용하고, 각자 `overflow-x: auto` 컨테이너를 갖습니다.

## 도표

- 도표에 쓰는 숫자는 전부 저장소 커밋 수, CSV, 측정 로그처럼 다시 셀 수 있는 것입니다. 각 도표 아래 출처 줄(`caption`, `muted`)이 있습니다.
- **스킬 막대**(`SkillBar`)는 5칸 세그먼트입니다. 4 이상은 `accent`, 3 이하는 `tint-strong`으로 채워 "핵심"과 "쓸 수 있음"이 색으로 갈립니다. 5칸은 비워 둡니다. 신입 포트폴리오에서 5점은 면접의 첫 공격 지점입니다. 별점이 없는 기술은 막대를 그리지 않고 "써 본 것" 한 줄 텍스트로 내립니다.
- **타임라인**(`Timeline`)은 세로 레일 하나에 점을 찍습니다. 날짜는 `meta`(mono), 진행 중인 항목만 점을 `accent`로 채웁니다.
- **통계 타일**(`StatTile`)은 숫자(`num`), 한 줄 설명, 출처 줄 세 층입니다. 타일을 네 개 넘게 나란히 두지 않습니다.
- 레이더 차트, 게이지, 퍼센트 원형은 쓰지 않습니다. 자기 평가를 측정처럼 보이게 하기 때문입니다.
- 색만으로 구분하지 않습니다. 막대의 두 색은 명도 차이가 있고, 옆에 숫자 라벨이 항상 붙습니다.

## 이동 배지와 GitHub README

- 이동 배지(`Badge`)는 Live · Demo · Case Study · Repo 네 종류입니다. 채움 `accent`, 글자 `on-accent`, `eyebrow` 스타일, `radius-sm`. 팀 프로젝트의 고유색(FINCH의 빨강·노랑 등)을 가져오지 않습니다.
- GitHub README에서는 같은 배지를 shields.io `for-the-badge`로 그립니다. 라이트 `2E4A8B`, 다크 `4C6CB3`을 `<picture>`로 갈라 넣습니다. 이 두 값이 `accent`의 두 테마 값입니다.
- 스택 배지는 README에서만 쓰고 사이트에서는 `Chip`으로 바꿉니다.

## 아이콘과 이미지

- 아이콘 세트가 없습니다. 글자와 선으로만 구성하고, 외부 링크 표시는 "→" 글자 하나입니다. 로고도 없습니다. 이름은 `display` 스타일의 글자로 적습니다.
- 인물 사진이나 아바타를 쓰지 않습니다. 레퍼런스에서 그 자리는 타이포와 도표가 대신합니다.
- 프로젝트 이미지는 실제 화면 캡처와 녹화뿐입니다. 전부 `radius-md` 이상의 둥근 모서리에 `line` 1px 테두리로 감쌉니다.

## 움직임

- 스크롤 진입 시 8px 올라오며 나타나는 것 하나만 씁니다. 지속 시간 400ms, 처음 상태도 보이는 상태입니다(투명도 0으로 기다리지 않습니다).
- 프리로더, 커스텀 커서, 마키(흐르는 글자), 자석 버튼, 스무스 스크롤 라이브러리를 쓰지 않습니다. 이전 사이트에 있던 것들이고 이 시스템에서 제거합니다.
- `prefers-reduced-motion`이면 모든 전환을 끕니다.

## 상태

- 포커스는 `focus` 토큰으로 2px 바탕색 간격 뒤 2px 실선입니다. 모든 버튼·배지·칩·링크에 `:focus-visible`로 붙입니다.
- hover는 채움 버튼이 `accent-strong`으로, 아웃라인 버튼이 `tint` 배경으로, 카드가 `shadow-soft`로 바뀌는 것뿐입니다. 크기가 변하거나 움직이지 않습니다.
- 비활성 상태는 없습니다. 포트폴리오에는 비활성 컨트롤이 없습니다.

## 쓰는 법

- 서체는 Google Fonts에서 불러옵니다. 페이지 `<head>`에 다음 한 줄을 둡니다.
  `<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+KR:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500;600&display=swap">`
- `tokens.css`를 먼저, `src/components.css`를 다음에 불러옵니다. 다크 테마는 `<html data-theme="dark">`로 켭니다.
- 컴포넌트는 `src/index.ts`에서 가져옵니다. 전부 React 19 함수 컴포넌트이고 스타일은 `components.css`의 `ty-` 클래스뿐입니다. Tailwind 유틸리티를 섞지 않습니다.
- 원본은 Claude의 「TrossYou 디자인 시스템」 아티팩트입니다. 토큰이나 컴포넌트가 바뀌면 그쪽을 먼저 고치고 이 폴더를 맞춥니다.
