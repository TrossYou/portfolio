# 표기 규격

포트폴리오 사이트, GitHub 프로필 README, 이 저장소의 README와 케이스 스터디 네 편이 함께 따르는 시각 규격입니다. 원본은 Claude Design의 「TrossYou 디자인 시스템」이고, 이 문서는 그 토큰과 패턴을 마크다운 작업에서 바로 쓸 수 있게 옮긴 것입니다. 값이 바뀌면 디자인 시스템을 먼저 고치고 이 문서를 따라 고칩니다.

주제는 하나입니다. **무엇을 결정했고, 무엇이 틀렸고, 무엇을 남겼는지.** 결과물의 전시가 아니라 판단의 기록으로 읽히게 만듭니다. 그래서 화려함 대신 여백·둥근 모서리·선 하나로 정돈하고, 숫자에는 전부 출처가 붙습니다.

## 색

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `ground` | `#FAFAFA` | `#0F1114` | 페이지 바탕. 순백·순흑은 쓰지 않되 푸른 기운도 두지 않는다 |
| `surface` | `#FFFFFF` | `#17191F` | 카드·스티커·표 바탕 |
| `tint` | `#E7ECFA` | `#1F2744` | 페리윙클 연한 채움. 칩, 콜아웃, 제목 단어 뒤 하이라이트 띠 |
| `tint-strong` | `#B9C7F2` | `#3B4C86` | 페리윙클 진한 채움. 섹션 제목 밑 막대, 스킬 막대, 타임라인 레일 |
| `ink` | `#1C1F27` | `#E9EAEE` | 본문·제목 글자, 스티커 테두리 |
| `muted` | `#5D6270` | `#A1A5B0` | 메타 줄, 캡션, 출처 줄, 아이브로우 |
| `line` | `#E2E4EA` | `#2A2D36` | 구분선, 표 괘선, 일반 카드 테두리 |
| `accent` | `#2E4A8B` | `#4C6CB3` | 남색 채움. 이동 배지, 기본 버튼. GitHub 배지 색과 같은 값 |
| `accent-strong` | `#243B70` | `#3D5A9E` | 채움의 hover |
| `accent-text` | `#2E4A8B` | `#9DB1EC` | 남색 글자. 링크, 강조 라벨 |
| `on-accent` | `#FFFFFF` | `#FFFFFF` | 남색 채움 위의 글자 |
| `focus` | `#2E4A8B` | `#9DB1EC` | 키보드 포커스 링 |

규칙은 넷입니다.

- 남색은 채움(`accent`)과 글자(`accent-text`)가 다른 토큰입니다. 다크에서 채움색을 글자로 쓰면 대비가 3.6:1로 떨어집니다.
- 페리윙클 두 토큰은 채움 전용입니다. 글자색으로 쓰지 않고, 섹션 전체 바탕으로 넓게 깔지도 않습니다. 칩·콜아웃·막대 같은 작은 면에만 씁니다.
- 글자는 `ink`와 `muted` 둘뿐이고, 본문을 `muted`로 쓰지 않습니다.
- 모든 글자·바탕 쌍은 두 테마에서 4.5:1 이상입니다.

## 서체

| 역할 | 서체 | 비고 |
|---|---|---|
| 본문·제목 | IBM Plex Sans KR | 세리프를 섞지 않는다. Pretendard는 템플릿 기본값이라 피했다 |
| 숫자·날짜·코드·아이브로우 | JetBrains Mono | 숫자가 세로로 정렬되는 곳은 `tabular-nums` |

| 스타일 | 크기/행간 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| `display-xl` | 56/62 | 700 | 홈 히어로 한 줄. 데스크톱만 |
| `display` | 40/48 | 700 | 케이스 스터디 제목, 모바일 히어로 |
| `h2` | 28/36 | 600 | 섹션 제목, 장 제목 |
| `h3` | 20/28 | 600 | 소제목, 카드 제목 |
| `lead` | 18/30 | 400 | 섹션 첫 문단 |
| `body` | 16/27 | 400 | 본문. 한글 행간 1.7 |
| `body-sm` | 14/22 | 400 | 카드 본문, 표 셀 |
| `caption` | 12/18 | 400 | 출처 줄, 캡션. `muted` |
| `eyebrow` | 12/16 mono | 500 | 영문 대문자, 자간 0.08em. 한글은 쓰지 않는다 |
| `num` | 28/32 mono | 600 | 통계 타일 숫자 |
| `meta` | 13/18 mono | 400 | 기간·인원 메타 줄, 타임라인 날짜 |

본문 한 줄은 36~40자, 약 680px를 넘기지 않습니다. 제목에는 `text-wrap: balance`를 줍니다.

GitHub README 안의 SVG는 웹폰트를 못 불러옵니다. 그 SVG는 시스템 산세리프(Apple SD Gothic Neo, Malgun Gothic)로 렌더되는 것을 전제로 글자 폭에 여유를 둡니다.

## 간격·모서리·선

| 단계 | 값 | 쓰는 곳 |
|---|---|---|
| `space-1`~`space-9` | 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96px | 형제 사이는 `gap`으로. 개별 margin을 쌓지 않는다 |
| `radius-sm` | 6px | 이동 배지, 코드 블록, 표 |
| `radius-md` | 14px | 일반 카드, 콜아웃, 이미지 |
| `radius-lg` | 22px | 스티커 카드, 큰 이미지 |
| `radius-pill` | 999px | 버튼, 칩 |
| `border-sticker` | 1.5px `ink` | 스티커 카드, 아웃라인 버튼 |
| `border-hair` | 1px `line` | 일반 카드, 표, 구분선 |

구분은 그림자가 아니라 선으로 합니다. 그림자는 hover한 카드에만 붙습니다. 왼쪽 세로 색띠로 강조하는 카드를 만들지 않습니다. 강조는 상단의 라벨 칩이나 아이브로우로 합니다.

스티커 카드는 한 화면에 한두 개입니다. 프로젝트 카드와 히어로 이미지가 스티커이고, 통계·성향·콜아웃처럼 여러 개가 나란히 서는 것은 일반 카드입니다.

## 이동 배지

Live · Demo · Case Study · Repo 네 종류입니다. 팀 프로젝트의 고유색은 가져오지 않습니다.

GitHub README에서는 shields.io `for-the-badge`로 그리고, 라이트 `2E4A8B`와 다크 `4C6CB3`을 `<picture>`로 가릅니다. 템플릿은 다음과 같고 `LABEL`과 `URL`만 바꿉니다. 로고가 필요한 것은 Demo(`logo=youtube`), Repo(`logo=github`), Send Mail(`logo=gmail`) 셋뿐입니다.

```html
<a href="URL"><picture><source media="(prefers-color-scheme: dark)" srcset="https://img.shields.io/badge/LABEL-4C6CB3?style=for-the-badge"><img src="https://img.shields.io/badge/LABEL-2E4A8B?style=for-the-badge" alt="LABEL"></picture></a>
```

스택 배지는 프로필 README에서만 쓰고, 사이트에서는 칩으로 바꿉니다.

## 케이스 스터디 머리 블록

네 편(`finch.md` `pinlog.md` `formabridge.md` `harness.md`)이 같은 순서를 따릅니다. 가운데 정렬 블록 하나에 **한 줄 소개(제목)**, 그 아래 **이름(작게)**, 메타 줄, 이동 배지 줄이 들어가고 구분선으로 끝납니다. 사이트는 이 구분선 이후부터 렌더합니다.

이름보다 한 줄 소개가 큽니다. 읽는 사람은 이름을 모르고 들어오므로 무엇을 만든 것인지가 먼저 보여야 합니다. 프로젝트 카드와 상세 페이지 머리도 같은 위계입니다. 서사형 제목("~했다")은 머리에서 빼고 본문 첫 줄에 굵게 둡니다.

```markdown
<div align="center">

# {서비스 한 줄 소개}

### {프로젝트 이름}

{메타 줄}

{이동 배지 줄}

</div>

---

**{서사형 제목}.**
```

메타 줄의 순서는 `기간 · 기간 길이 · 인원 · 맥락 · 역할`이고 구분자는 ` · `입니다. 기간은 `2026.08–09`처럼 연.월 사이를 짧은 줄표(–)로 잇습니다. 모르는 항목은 비우되 순서를 바꾸지 않습니다. 예: `2026.08–09 · 6주 · 5인 · SSAFY · 프론트엔드 구현 전반`.

서사형 제목은 "~했다"로 끊고, 본문은 "~했습니다"로 씁니다.

본문의 장(h2) 끝에 종류 주석을 붙이면 사이트가 결정 · 틀림 · 남김 표시로 그립니다. GitHub에서는 보이지 않습니다.

```markdown
## 401만 보고 사용자를 로그아웃시키면 안 됐다 <!-- kind: 틀림 -->
```

## 배치

화면은 읽는 순서대로 쌓이고, 섹션마다 훑는 층(숫자·메타·태그)이 읽는 층(문장)보다 먼저 옵니다.

- **홈 순서**: 히어로 → Selected Work → 활동 타임라인 → Skills → How I Work(성향 카드) → Contact. 프로젝트 다음에 시간 축, 그다음에 기술입니다. About 섹션은 따로 두지 않습니다. 교육·학력·자격은 타임라인이, 성향은 근거 카드가 맡습니다.
- **히어로**: 한 문장 주장과 한 줄 보조 문장, 버튼 둘, 그 아래 교육 · 학력 · 자격 세 칸의 사실 격자. 이름은 헤더에 있으니 인사말로 시작하지 않습니다.
- **Selected Work**: 대표작 하나를 이미지 왼쪽·글 오른쪽의 가로형 스티커로 넓게, 나머지를 2열 격자로. 카드마다 맥락 태그(SSAFY · 공모전 · 수업)가 붙고, 대표작·수상 표시는 남색 태그 하나만.
- **Skills**: 프론트엔드 · 백엔드 두 묶음을 나란한 열로. 각 줄은 이름과 점 다섯 개뿐이고, 맨 아래 "써 본 것"과 기준(구어체)을 작게 둡니다. 4점은 색이 달라 따로 묶지 않아도 눈에 띕니다. 아이콘 띠나 흐르는 로고 줄은 쓰지 않습니다.
- **활동 타임라인**: 항목마다 종류 태그(교육 · 프로젝트 · 자격 · 수상)가 날짜 옆에 붙고, 축의 표식 모양도 종류를 따릅니다. 프로젝트는 원, 교육은 정사각형, 자격은 마름모, 수상은 잉크로 채운 마름모. 진행 중만 남색으로 채워집니다. 세부 항목은 4px 회색 점으로 두세 줄까지.
- **Contact**: 폼 없이 사실 둘. 이메일 · GitHub를 사실 격자로. 위치는 적지 않습니다.
- **프로젝트 상세 머리**: 이름과 한 줄 설명 아래 사실 격자 네 칸(기간 · 역할 · 규모 · 기여), 통계 타일 두세 개, 담당 범위 표, 장 목록. 데스크톱에서는 장 목록이 왼쪽에 고정되어 따라옵니다.
- **본문의 장**: 제목 위에 종류 표시 하나. 값은 **결정**(남색 점) · **틀림**(잉크 점) · **남김**(페리윙클 점) 셋뿐입니다. 장 제목은 "~했다" 문장 그대로 두고, 상황·과제·행동·결과 같은 정형 틀로 바꾸지 않습니다. 글은 서사이고 표시는 색인입니다.
- 두지 않는 섹션: 블로그 글 목록, 메시지 폼, 터미널 창 흉내, 방문자 수.

## 도표

도표에 쓰는 숫자는 저장소 커밋 수, CSV, 측정 로그처럼 다시 셀 수 있는 것만입니다. 각 도표 아래에 출처 줄이 있습니다.

- **스킬 점.** 점 다섯 개. 채운 수가 등급이고 4점은 `accent`, 3점은 `tint-strong`이라 색으로도 갈립니다. 다섯 번째는 비워 둡니다. 숫자 라벨 없이 점 수가 말하고, 기준은 맨 아래 작게 구어체로 적습니다. 별점이 없는 기술은 점 없이 "써 본 것" 한 줄입니다. 현재 값은 `data/skills.json`에 있습니다.
- **타임라인.** 세로 레일 하나에 점. 진행 중인 항목만 점을 채웁니다. 가로 타임라인은 모바일에서 접히지 않아 쓰지 않습니다.
- **통계 타일.** 숫자, 한 줄 설명, 출처 세 층. 한 줄에 네 개까지.
- **성향 카드.** 공고의 인재상 표현을 라벨로, 그 아래 실제로 한 일 한 문장과 케이스 스터디 링크. 점수는 없습니다. 한 줄에 세 장까지.
- 레이더, 게이지, 퍼센트 원형은 쓰지 않습니다. 자기 평가를 측정처럼 보이게 하기 때문입니다.

## 쓰지 않는 것

- 이모지, 느낌표, "최고의"·"혁신적인" 같은 수식어
- 인물 사진과 아바타. 그 자리는 타이포와 도표가 맡는다
- 아이콘 세트와 로고. 외부 링크 표시는 "→" 글자 하나
- 프리로더, 커스텀 커서, 마키, 자석 버튼, 스무스 스크롤 라이브러리
- 화면 높이에 맞춘 히어로. 첫 화면 안에 Selected Work의 첫 카드가 걸리게 둔다
- 스크롤 진입 이외의 움직임. 진입도 8px 올라오며 나타나는 400ms 하나이고, 처음 상태가 보이는 상태다
