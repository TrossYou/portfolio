# 표기 규격

포트폴리오 사이트, GitHub 프로필 README, 이 저장소의 README와 케이스 스터디 네 편이 함께 따르는 시각 규격입니다. 원본은 이 저장소의 `design-system/`(토큰은 `tokens.json`)이고, 이 문서는 그 토큰과 패턴을 마크다운 작업에서 바로 쓸 수 있게 옮긴 것입니다. 값이 바뀌면 디자인 시스템을 먼저 고치고 이 문서를 따라 고칩니다.

주제는 하나입니다. **무엇을 결정했고, 무엇이 틀렸고, 무엇을 남겼는지.** 결과물의 전시가 아니라 판단의 기록으로 읽히게 만듭니다. 그래서 화려함 대신 여백·둥근 모서리·선 하나로 정돈하고, 숫자에는 전부 출처가 붙습니다.

## 색

2026.11.20에 남색 · 페리윙클에서 흰 바탕 · 중립 회색 · 초록 하나로 바꿨습니다(토큰 v2). 바탕에 베이지 · 크림 같은 따뜻한 색을 쓰지 않습니다.

| `focus` | `#23705A` | `#7FD0B3` | 키보드 포커스 링. 2px 바탕색 간격 뒤 2px 실선. |

규칙은 넷입니다.

- 강조색은 초록 하나입니다. 채움(`accent`)과 글자(`accent-text`)가 다른 토큰이고, 다크에서는 값이 다릅니다.
- 강조색은 섹션 머리말 · 버튼 · 막대 · 결과 숫자 하나에만 씁니다. 한 화면에 넓게 깔지 않습니다. 넓은 띠는 중립 회색 `band`가 맡습니다.
- 글자는 `ink`(제목 · 숫자) · `ink-soft`(본문) · `muted`(기준 줄 · 메타) 셋입니다.
- 모든 글자 · 바탕 쌍은 두 테마에서 4.5:1 이상입니다. 버튼 초록은 흰 글자와 5.0:1이 되도록 시안의 `#2E8A6C`보다 한 단계 어둡게 잡았습니다.

## 이동 배지

Live · Demo · Case Study · Repo 네 종류입니다. 팀 프로젝트의 고유색은 가져오지 않습니다.

GitHub README에서는 shields.io `for-the-badge`로 그립니다. 색은 `accent`의 `2A7D62` 하나입니다. 두 테마에서 같은 값이라 `<picture>`로 가르지 않습니다(2026.11.20 토큰 v2). 템플릿은 다음과 같고 `LABEL`과 `URL`만 바꿉니다. 로고가 필요한 것은 Demo(`logo=youtube`), Repo(`logo=github`), Send Mail(`logo=gmail`)뿐입니다.

```html
<a href="URL"><img src="https://img.shields.io/badge/LABEL-2A7D62?style=for-the-badge" alt="LABEL"></a>
```

스택 배지는 프로필 README에서만 쓰고, 사이트에서는 칩으로 바꿉니다.

## 케이스 스터디 머리 블록

다섯 편(`finch.md` `glocare.md` `pinlog.md` `formabridge.md` `harness.md`)이 같은 순서를 따릅니다. 가운데 정렬 블록 하나에 **한 줄 소개(제목)**, 그 아래 **이름(작게)**, 메타 줄, 이동 배지 줄이 들어가고 구분선으로 끝납니다. 공개 링크가 없는 편(`glocare.md`, 팀 저장소 비공개)은 배지 줄을 비웁니다. 사이트는 이 구분선 이후부터 렌더합니다.

이름보다 한 줄 소개가 큽니다. 읽는 사람은 이름을 모르고 들어오므로 무엇을 만든 것인지가 먼저 보여야 합니다. 프로젝트 카드와 상세 페이지 머리도 같은 위계입니다. 서사형 제목("~함")은 머리에서 빼고 본문 첫 줄에 굵게 둡니다.

```markdown
<div align="center">

# {서비스 한 줄 소개}

### {프로젝트 이름}

{메타 줄}

{이동 배지 줄}

</div>

---

**{서사형 제목}**
```

메타 줄의 순서는 `기간 · 기간 길이 · 인원 · 맥락 · 역할`이고 구분자는 ` · `입니다. 기간은 `2026.08–09`처럼 연.월 사이를 짧은 줄표(–)로 잇습니다. 모르는 항목은 비우되 순서를 바꾸지 않습니다. 예: `2026.08–09 · 6주 · 5인 · SSAFY · 프론트엔드 구현 전반`.

서사형 제목 · 장 제목 · 본문은 모두 명사형 어미("~함" "~됨" "~였음")로 끝내고 마침표를 붙이지 않습니다. 본문은 문단 대신 개조식 불릿으로 쓰고, 딸린 이유·대안은 한 단계 아래 불릿으로 둡니다. 화면 · README 문장도 같은 어미입니다(2026-10-27).

본문의 장(h2) 끝에 종류 주석을 붙이면 사이트가 결정 · 틀림 · 남김 표시로 그립니다. GitHub에서는 보이지 않습니다.

```markdown
## 401만 보고 사용자를 로그아웃시키면 안 됐음 <!-- kind: 틀림 -->
```

## 배치

화면은 읽는 순서대로 쌓이고, 섹션마다 훑는 층(숫자·메타·태그)이 읽는 층(문장)보다 먼저 옵니다.

- **홈 순서**: 히어로 → Selected Work → 활동 타임라인 → Skills → How I Work(성향 카드) → Contact. 프로젝트 다음에 시간 축, 그다음에 기술입니다. About 섹션은 따로 두지 않습니다. 교육·학력·자격은 타임라인이, 성향은 근거 카드가 맡습니다.
- **히어로**: 한 문장 주장과 한 줄 보조 문장, 버튼 둘, 그 아래 교육 · 학력 · 자격 세 칸의 사실 격자. 이름은 헤더에 있으니 인사말로 시작하지 않습니다.
- **Selected Work**: 대표작 하나를 이미지 왼쪽·글 오른쪽의 가로형 스티커로 넓게, 나머지를 2열 격자로. 카드마다 맥락 태그(SSAFY · 공모전 · 수업)가 붙고, 대표작·수상 표시는 남색 태그 하나만. 카드 아래에는 장면 셋(`data/highlights.json`)을 둡니다. 장면마다 본문의 장과 같은 종류 표시와 문제 · 판단 · 결과 세 줄이 있고 결과 줄만 크고 굵으며, 대표작은 카드 폭에 세 칸, 나머지는 카드 아래로 쌓고(좁아지면 한 열) 끝에 케이스 스터디 링크를 답니다. 장면이 없는 프로젝트는 카드만 둡니다.
- **Skills**: 프론트엔드 · 백엔드 두 묶음을 나란한 열로. 각 줄은 이름과 점 다섯 개뿐이고, 맨 아래 "써 본 것"과 기준(구어체)을 작게 둡니다. 4점은 색이 달라 따로 묶지 않아도 눈에 띕니다. 아이콘 띠나 흐르는 로고 줄은 쓰지 않습니다.
- **활동 타임라인**: 항목마다 종류 태그(교육 · 프로젝트 · 자격 · 수상)가 날짜 옆에 붙고, 축의 표식 모양도 종류를 따릅니다. 프로젝트는 빈 원, 교육은 페리윙클로 채운 정사각형, 자격은 페리윙클로 채운 마름모, 수상은 잉크로 채운 마름모. 진행 중인 프로젝트만 남색으로 채워집니다. 빈 도형끼리는 작은 크기에서 구분되지 않아 교육·자격은 채움으로도 가릅니다(2026-10-03). 세부 항목은 4px 회색 점으로 두세 줄까지. 항목이 여섯을 넘으면 데스크톱에서 두 열로 나눕니다. 왼쪽이 과거, 오른쪽이 최근이고 좁아지면 한 열로 이어집니다.
- **Contact**: 폼 없이 사실 둘. 이메일 · GitHub를 사실 격자로. 위치는 적지 않습니다.
- **프로젝트 상세 머리**: 이름과 한 줄 설명 아래 사실 격자 네 칸(기간 · 역할 · 규모 · 기여), 통계 타일 두세 개, 담당 범위 표, 장 목록. 데스크톱에서는 장 목록이 왼쪽에 고정되어 따라옵니다.
- **본문의 장**: 제목 위에 종류 표시 하나. 값은 **결정**(남색 점) · **틀림**(잉크 점) · **남김**(페리윙클 점) 셋뿐입니다. 장 제목은 명사형 한 문장으로 두고, 상황·과제·행동·결과 같은 정형 틀로 바꾸지 않습니다. 본문은 개조식이되 일이 벌어진 순서를 따르고, 표시는 색인입니다.
- 두지 않는 섹션: 블로그 글 목록, 메시지 폼, 터미널 창 흉내, 방문자 수.

## 도표

도표에 쓰는 숫자는 저장소 커밋 수, CSV, 측정 로그처럼 다시 셀 수 있는 것만입니다. 각 도표 아래에 출처 줄이 있습니다.

- **스킬 점.** 점 다섯 개. 채운 수가 등급이고 4점은 `accent`, 3점은 `tint-strong`이라 색으로도 갈립니다. 다섯 번째는 비워 둡니다. 숫자 라벨 없이 점 수가 말하고, 기준은 맨 아래 작게 구어체로 적습니다. 별점이 없는 기술은 점 없이 "써 본 것" 한 줄입니다. 현재 값은 `data/skills.json`에 있습니다.
- **타임라인.** 세로 레일 하나에 점. 진행 중인 항목만 점을 채웁니다. 가로 타임라인은 모바일에서 접히지 않아 쓰지 않습니다.
- **통계 타일.** 숫자, 한 줄 설명, 출처 세 층. 한 줄에 네 개까지.
- **성향 카드.** 공고의 인재상 표현을 라벨로, 그 아래 실제로 한 일 한 문장과 케이스 스터디 링크. 점수는 없습니다. 한 줄에 세 장까지.
